- stripall {set} {clear} {list} {f} {o} {e} {fig}                                
    Visits sectors in list and strips the planets there.     
       - default will visit all planets on the tl list       
                                                            
    [set] {sector1} {sector2} {...} {sectorx}               
       - set puts sectors in the order you enter into a file
    [clear]                                                 
       - clear deletes the farm file                        
    [list]                                                  
       - show lists of all sectors in the farm file in order
       
    {personal}   
       - goes to all personal planets instead of corp
       
   {f} - strips fuel ore
   {o} - strips organics
   {e} - strips equipment
   {fig} - strips fighters
       - default is all
